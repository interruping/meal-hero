# Meal Hero

빚에 쫓기는 주인공이 서울 빌라촌 골목에서 사계절 배달로 빚을 갚아나가는 **레트로 3D 배달 러너**.
NAN 2026 해커톤 사전 과제 제출작.

## ▶ 플레이

**https://interruping.github.io/meal-hero/**

설치·로그인 없이 링크 접속만으로 플레이할 수 있습니다. (데스크톱 Chrome 권장, 모바일 미지원)

### 조작

| 키 | 동작 |
|---|---|
| W A S D | 이동 (카메라 기준) |
| 마우스 | 시점 |
| Space | 점프 |
| 1 ~ 4 | 배달 의뢰 수락 / 수령 영수증 선택 |
| E | 음식 픽업 / 전달 |
| M (홀드) | 네비게이션 스마트폰 |
| Shift | 스페셜 스킬 (부스트) |
| R | 게임오버 시 재시작 |

### 게임 규칙

- 상단 의뢰 슬롯(10초 안에 사라짐)에서 **1~4**로 수락 — 동시 최대 3건, 배달마다 색깔 마커
- 상가에서 **E**로 픽업 — 3초 안에 내 접수증과 일치하는 주문 영수증을 골라야 한다 (틀리면 -5초)
- 제한 시간 안에 빌라 현관까지 배달 → 건당 5,000원, 제한 시간 70% 이내면 +50% 보너스
- 시간 초과는 수수료 -3,000원. **순수익이 음수가 되면 게임오버**
- 스테이지는 10분 — 종료 시 "10분 순수익 × 120일" 분기 정산으로 빚 2,000만원을 갚는다. 계절이 바뀌면 더 빠른 탈것 (구보 → 킥보드 → 자전거 → 스쿠터)
- 방해요소(전단지 알바생·자전거 초딩·비둘기·취객)와 충돌하면 페널티
- 타이틀의 **심사 모드**에서 4개 스테이지를 바로 체험할 수 있다

## 로컬 실행

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/ 정적 빌드
```
