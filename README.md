# Meal Hero

빚에 쫓기는 주인공이 서울 빌라촌 골목에서 사계절 배달로 빚을 갚아나가는 **레트로 3D 배달 러너**.
NAN 2026 해커톤 사전 과제 제출작.

## ▶ 플레이

**https://interruping.github.io/meal-hero/**

설치·로그인 없이 링크 접속만으로 플레이할 수 있습니다. (데스크톱 Chrome 권장, 모바일 미지원)

### 조작

| 키 | 동작 |
|---|---|
| W A S D | 이동 (카메라 기준) |
| 마우스 | 시점 |
| Space | 점프 |
| E | 음식 픽업 / 전달 |
| Shift | 스페셜 스킬 (부스트) |
| R | 게임오버 시 재시작 |

### 게임 규칙

- 주문 수락 → 상가에서 **E**로 픽업 → 제한 시간 안에 빌라 현관까지 배달 → 보수 획득
- 스테이지 목표 상환액을 달성하면 계절이 바뀌고 더 빠른 탈것을 얻는다 (구보 → 킥보드 → 자전거 → 스쿠터)
- 방해요소(전단지 알바생·자전거 초딩·비둘기·취객)와 충돌하면 페널티
- 체력 소진 또는 배달 시간 초과 3회 누적 시 게임오버
- 타이틀의 **심사 모드**에서 4개 스테이지를 바로 체험할 수 있다

## 로컬 실행

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/ 정적 빌드
```
